## How this inventory was checked

Direct filesystem discovery matched `sources/Delvers *.parakeet.processed.srt` and each exact-basename Qwen companion, then checked for the corresponding direct-root `local/Delvers *.mp3`. The two-model set accounts for all **74** Delvers SRTs currently under `sources/`; the matched audio set accounts for all **37** direct-root Delvers MP3s. Each export was checked for nonzero size and SRT timing lines. Nested alternate recordings and private assets are outside those audio counts.

The local checkout was on `main` at `76cb96b` with existing uncommitted E120 documentation work. This inventory describes that local state; it does not assert synchronization with GitHub or an MCP workspace. Original SRTs and audio were not edited. Recheck availability and source identity when each entry is analyzed.
